# ChronoKinesis privacy policy

Public hosting for the ChronoKinesis (`org.chronokinesis.game`) privacy
policy, served via GitHub Pages at
<https://nickmargar.github.io/chronokinesis-privacy/> and referenced from the
Google Play Console listing.

`index.html` is **generated** — do not hand-edit it. The source of truth is
`docs/privacy-policy.md` in the game repo; regenerate with
`python tools/gen_privacy_page.py` and copy the result here.
